# Omni-iEEG planner：解析結果の表示と出力（RC17）

## 操作

1. 患者を選び、上部の「解析表示」を開きます。
2. 共通の「解析Excelを追加」で `.xlsx` を選択します。複数選択できます。時間のない結果は「静的結果」、時間列のある結果は「時系列結果」のタブへ振り分け、最初に選んだファイルの結果を表示します。同じ内容のファイルは二重登録せず、登録済みの結果を表示します。時間単位は「時間・再生」でms／sを指定し、値の単位は自動で決めません。保存済みの単位を読み直しやタブ切替で変更することはありません。
3. 結果と指標を選びます。HFOは `total_events`、`spike_associated`、`ehfo_predicted` など、元Excelの列をそのまま選択できます。件数を時間当たりの率に換算しません。
4. 「電極位置にカラーマップを表示」を押します。名前が未対応なら対応画面が開き、対応を保存すると脳画像に切り替わります。「チャンネル別」では全チャンネルの値を確認できます。「色の下限・上限」は全フレームで固定し、同じ色が同じ値を表します。n/aは欠損で、0とは区別します。単位欄は表示ラベルであり、入力しても値の換算は行いません。
5. HFOは「静止画 PNG」を選びます。時系列も現在の時間を静止画にできます。
6. gammaは時間スライダーで移動し、「再生」で時間列を順番に表示します。画像上部にも再生・停止・前後の時点・時間スライダーがあり、左側の設定をスクロールしても操作できます。「列/秒」は再生と動画のフレームレートです。1フレーム＝1時間列で、補間しません。例えば10 ms刻みを20列/秒にすると、実時間の5倍の長さで表示します。時間単位を確認するまでは「未確認」と表示します。
7. 「動画 MP4」で選択した範囲を書き出します。範囲はデータの時間列を1から数えます（1＝ExcelのB列）。重複・逆行した時間を含む範囲は動画にできません。元データは並べ替えたり切り捨てたりせず、範囲を変えてもすべて保持します。

静止画・動画には結果名、指標、時間または静的結果の表示、値の単位、色尺度、位置対応数を添えます。JSONには元Excelのハッシュ、シート・行・列、出力値、元の時間、選択範囲、表示条件、対応するコンタクトIDと現在の座標を保存します。PNGは1800×1120、MP4は同解像度のH.264です。書き出しを中止した場合は途中ファイルを公開せず、既存の出力を残します。

タブを切り替えると再生を停止し、それぞれで直前に選んだ結果・時間位置・表示設定を引き継ぎます。「静的結果」は静止画出力、「時系列結果」は動画と任意時点の静止画出力を使えます。結果のないタブでは前の結果を表示し続けず、未読込と表示します。画像・測定値・描画部品は両タブで共有するため、切替のための画像再読込や配列の複製はありません。

上部「画像出力」も解析表示中は解析PNGの出力になります。通常の出力先は患者フォルダ内のexportsです。解析の追加後、患者切替時、通常終了時に保存し、上部「保存」も随時使えます。保存後は元Excelがなくても値・時間・対応・表示設定を再開できます。

## 電極との対応

「電極との対応を確認・指定」は独立した画面です。開いたまま脳画像を確認できます。

- 開いた時点で「チャンネルごと」に名前からの候補が入ります。`LPH1-LPH2`、`LPH01-LPH02`、`LPH-01-LPH-02`は、画像側の`LPH-01`と`LPH-02`に対応できます。大小文字・全角英数字・ハイフン前後の空白も吸収し、電極名自体に含まれるハイフンや数字は保持します。接点の不足・重複は未対応として表示します。候補を確認し「確認して保存」で反映、キャンセルなら従来の対応を保持します。
- 「未対応のみ表示」で確認対象を絞れます。「名前から自動照合」は空欄だけを再照合し、保存済みの対応や手動選択を上書きしません。チャンネル名のダブルクリックで画像上の位置へ移動します。接点1・2の並びはチャンネル名の順序を保持します。解析値の符号を変更しません。
- 「電極名でまとめて指定」では、解析側の電極名とCT側の電極名、番号方向を指定して候補を作ります。存在しない番号は割り当てません。最終的にチャンネル表で確認し、「Save」で確定します。
- gammaの省略名には「他の結果から名前・接点の候補を表示」を使えます。HFOなど同じ患者に読み込んだ結果に一意の完全名があれば表示し、同名の対応情報が一意なら接点候補も示します。候補を確認して保存するまで、実際の対応は変わりません。
- 読込時の一意な完全一致は従来どおり使用します。表記差を吸収する自動照合は対応画面で確認して保存します。両端の名前と番号が一意に決まる場合だけ候補を作り、行順や近接位置から電極の同一性を推測しません。`LPH1-LPH`や`LPH1-2`のような端点の省略は自動補完しません。
- 対応はコンタクトの固定IDで記録します。位置を手動修正すると表示も追従します。接点を削除・再検出してIDがなくなった場合は未対応に戻ります。

「脳画像（4画面）」は現在の画像配置、「脳画像（3D出力）」は同じ画面で確認し、出力には3Dだけを使います。双極チャンネルは2接点の中点へ表示します。欠損・未対応の行は脳画像に表示しません。

## 色と電極表示の調整

- 「電極のカラーマップ」で自動／Inferno／Turbo／Viridis／青・白・赤／Jetを選び、色の向きを反転できます。画像上部と出力に同じカラーバー・範囲・単位を表示します。
- 「指定値以上」はその値以上、「絶対値が指定値以上」は正負どちらも大きさがしきい値以上の点を着色します。境界は含めます。値の符号・値そのものは変えません。チャンネル別一覧には除外前の全値を残します。
- 色球の半径（既定2 mm）、不透明度、2D表示の厚み（既定4 mm＝断面の前後2 mm）、チャンネル名の表示を変更できます。半径と厚みは表示条件であり、記録範囲の推定ではありません。
- 着色中は元の電極位置・軸を灰色にし、解析の色尺度と区別します。解析表示を離れるか重ね合わせを外すと、通常の電極色に戻ります。
- 「脳表の不透明度」は画像表示タブと連動します。深部電極の確認時にも解析画面から変更できます。
- 色・しきい値・表示条件は患者保存に含めます。出力JSONは表示設定と時点ごとの着色チャンネルを記録し、元の測定値も保持します。

## 脳表ヒートマップ（RC17）

「3D表示方法」は「接点の色球」「脳表ヒートマップ」「脳表ヒートマップ＋色球」から選べます。既存の患者は従来の色球表示から切り替えます。表示距離は1〜50 mm、初期値15 mmです。スライダーと数値入力が連動します。2D断面は接点・双極中点の位置に色球を表示し、脳表の色をMRIの組織値としては扱いません。

各脳表頂点から最大4個の近い接点／双極中点を求め、指定距離内にある有限値を距離の逆二乗で重み付けし、重みの合計で割ります。接点と一致する頂点はその値を使います。距離は患者固有RASの3次元直線距離です。脳溝に沿う距離・電流モデル・脳波の感度分布の推定は行いません。深部の接点は、その距離内に脳表がなければ脳表を着色しません。「＋色球」で元の位置を併記できます。

欠損の接点は補間への寄与から除外し、近傍に有限値がなければ着色しません。0は有効な値として扱います。元のExcelの値は保持し、しきい値を補間後の脳表値に適用します。色球には元のチャンネル値でしきい値を適用するため、境界の表示が異なることがあります。色尺度は従来どおり全時間で固定し、未設定なら元の全チャンネル・全時間の範囲を使います。距離や色範囲を変えると図の見え方が変わるため、PNG/MP4と一緒に出力されるJSONの`spatial_display`に方法・距離・近傍数を記録します。

時間・色・しきい値・距離だけの変更では近傍検索結果を再利用します。電極位置・対応・患者・メッシュが変わると再計算します。補間は表示時の計算で、元の画像や表面・コンタクト・測定値を上書きしません。ヒートマップを外すと通常の脳表色または設定済みのPET色へ戻ります。

### Brainstormでの広がりの意味

公式チュートリアルは、脳表上の色を近傍のSEEG接点から補間し、`Channel > Edit interpolation distance`で接点から着色頂点までの最大距離を変えると説明しています。[公式ECoG/sEEG説明](https://neuroimage.usc.edu/brainstorm/Tutorials/ECoG#Interpolate_on_the_anatomy)

2026-09-24に確認した公開コードのSEEG/ECoGの初期値は0.015 m（15 mm）で、表示処理は近い4点を指定してShepard系の補間を呼びます。15 mmは中心からの距離であり、接点の直径や実測された記録半径ではありません。[初期値](https://github.com/brainstorm-tools/brainstorm3/blob/master/toolbox/core/bst_get.m)、[表面表示処理](https://github.com/brainstorm-tools/brainstorm3/blob/master/toolbox/gui/panel_surface.m)、[重みの実装](https://github.com/brainstorm-tools/brainstorm3/blob/master/toolbox/math/bst_shepards.m)

添付された過去のTIFFだけでは、その作成時の距離・表面の種類・色尺度の数値設定は確定できません。本アプリは同様の表示目的に対し、NumPy/SciPyによる正規化した逆二乗距離重みを実装しました。BrainstormのMATLABコードの複製・他言語への移植ではなく、同ソフトの重み式やゼロ・欠損処理と完全に一致する数値再現は保証しません。参照履歴は公開前のライセンス確認対象に含めます。

### RC17の確認範囲

合成データで、自動照合の重複・不足・番号順序・保存と取消、双極中点、補間の距離境界・0と欠損・符号、PET色の復元、表示条件の保存を検証しました。アプリ上で静止画出力と3フレームの脳表ヒートマップ動画を出力し、デコード後のフレーム数・色の時間変化・補間条件のJSON記録を確認しました。

## 入力形式と拡張

| 形式 | 読み込む内容 | 用途 |
| --- | --- | --- |
| pyHFO Excel | `Channel Ranking` の先頭表。最初の空見出しまでの数値列 | 静的な件数表示 |
| 汎用の静的Excel | 最初のシート。1行目が指標名、A列がチャンネル、B列以降が数値 | 静止画向けの解析結果 |
| 時系列Excel | 最初のシート。B1以降が数値の時間、A列がチャンネル | gammaなどの動画向けの解析結果 |

番号列の次に `channel_name` があるHFOの統合集計表にも対応しました。名前列の右側で、見出しのある最初の連続した指標群を読みます。無見出しの種別・電極名列と、空列の後の別ランキング表は結合しません。

値は数値、または数値を表す文字列に対応します。空欄・NA・n/a・NaNは欠損として保持します。重複したチャンネル名、不正な数値、数式の計算キャッシュがない表は読込時に知らせます。数式・マクロ・外部参照を実行しません。元Excelは変更しません。ファイルの時間値だけからms/s、%、z scoreなどを推定しません。

内部では「チャンネル×時間×指標」の共通形式を使い、静的結果は時間数1として扱います。追加の解析形式は `analysis_results.py` の読込部分に変換処理を加え、表示・対応・保存・動画出力を再利用できます。NPZの値とJSONのメタ情報を患者の自己完結した保存に含めます。RC14は既存のcortex-viewer/9保存形式と互換です。
