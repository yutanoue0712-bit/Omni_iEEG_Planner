# RC20 の開始方法

## 1. まず合成デモを開く

[README](../README.md) のインストール手順を実行し、`--demo` を指定します。
このデモはプログラム内で生成するため、患者画像の入力は不要です。

## 2. 自分の画像を使う

通常の起動は `Start_Viewer.cmd` です。「新規患者」で作業用の症例を作り、
「画像を追加」から基準MRIと、それに対応するFreeSurfer出力を選びます。
FreeSurferフォルダは `mri` と `surf` を含む処理結果のフォルダです。
追加MRIやCTは、その症例へ追加します。画像同士の位置合わせは表示で確認してください。

## 3. 電極と領域を確認する

術後CTから作成した電極候補は、コンタクト確認画面で位置・本数・個数・順序を確認します。
セグメンテーションでは、既存ラベルまたは手描きの領域を表示・編集できます。
候補や補間表示は、臨床的な正しさを保証する結果ではありません。

## 4. 解析結果を表示する

「解析表示」から「解析Excelを追加」を選びます。静的な表と時系列の表に対応します。
チャンネルと電極の対応を確認し、値の単位・時間単位を指定します。
[入力形式・色・脳表表示・出力](ANALYSIS_RESULTS.md)に詳しい説明があります。

## 5. 保存する

「保存」で症例ごとの状態を保存します。画像、領域、解析値や出力は作業フォルダ内に
作られます。自分の症例を使って作成されたファイルは、公開リポジトリへ追加しないでください。
この公開準備コピー自体には症例データを入れていません。
